# いわし赤坂 来店ガイド

店舗情報と公式のお知らせにアクセスできる静的サイトです。GitHub Pages の `main` ブランチのルートから配信できます。

ローカル確認

```sh
python3 -m http.server 8011 --bind 127.0.0.1
```

ブラウザで http://127.0.0.1:8011/ を開きます。

店舗情報の参照先

- [いわし赤坂 店舗公式X](https://x.com/iwashi_poker)
- [赤坂のポーカー店舗ガイド](https://light-three.com/akasaka-poker/)
